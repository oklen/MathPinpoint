\section*{Ethics Statement}

\paragraph{Data and licenses.} The documents are cleaned extractions of public web pages distributed in UltraData-Math under Apache-2.0. We release the corpus, queries and labels under CC0 1.0 and the prompts, schemas and code under Apache-2.0; rights in the original web pages remain with their owners. The pages carry no URLs. We did not run a dedicated filter for personal information; the pages come from a tier selected by a mathematical quality classifier.

\paragraph{Model-generated labels.} Every label was produced by a language model, and the LLM judges and the 8B model can share systematic errors that agreement between them does not reveal. We release each row's judge and the 8B model's raw score so that users can choose which labels to trust, and the exact prompts so that the labels can be audited or regenerated.

\paragraph{Use.} A retriever that finds worked solutions to a given problem can help learners check their work and can also be used to look up homework answers; this is true of any search engine over the same pages. We release the data to improve retrieval and its evaluation.
